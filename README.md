# ricardoaistudio
Projects

- [`editor/`](editor/): editor de vídeos curtos: legendas animadas, texto atrás da pessoa, cortes, B-roll, clipes, voz e marca (Remotion + Whisper + Claude). Veja o [`editor/README.md`](editor/README.md).

**Windows:** baixe o projeto (Code → Download ZIP), descompacte e dê dois cliques em `instalar-windows.bat`. Depois abra o atalho **Ricardo AI Studio** na Área de Trabalho: o app visual abre no navegador.
